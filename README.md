# ClaimCheck AI

## Project Overview



## Research Question

Can an NLP system identify whether a claim is supported, refuted or lacks sufficient evidence by retrieving and analysing relevant source documents?

## Dataset Source

https://fever.ai/dataset/fever.html

## Dataset Version & Components
v1.0: Contains 185,445 claims derived from altered Wikipedia sentences, labeled as SUPPORTS (SUPPORTED), REFUTES (REFUTED), or NOT ENOUGH INFO (NOTENOUGHINFO). Evidence sentences are recorded for supported and refuted claims


## Dataset Description
The FEVER (Fact Extraction and VERification) dataset includes v1.0 (the original 185,445-claim benchmark) 

## Data Files

The dataset is distributed in JSONL format (one JSON object per line) for automated fact-checking and claim verification against Wikipedia.

## Known Limitations

FEVER was constructed around Wikipedia evidence. It is a useful research benchmark, but it does not represent every type of contemporary misinformation or every real-world fact-checking situation
